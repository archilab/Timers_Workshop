# Custom GPT — Folkwang_Timers

Der Custom GPT **Folkwang_Timers** ist ein **didaktischer Arduino-Nano-Projektgenerator** für den **Timers Workshop**: vollständige Antworten mit **Verdrahtung**, **PlatformIO**-Dateien, **RTC-Setup** (`SETTIME`) und Erklärung für Anfänger.

**Hardware:** Arduino Nano (ATmega328P), **DS3231**, **VL53L0X**, **SSD1306**, **MPU6050**, **NeoPixel-Ring** (12× WS2812B, **D10**), **Servo** (**D9**).
